# To-Do List Application (Laravel & MySQL)

Aplikasi manajemen tugas harian berbasis web yang dibangun menggunakan framework Laravel, MySQL, dan Tailwind CSS.

## Fitur Utama
- **Manajemen Tugas (CRUD):** Menambah, melihat, memperbarui status, dan menghapus tugas.
- **Prioritas Tugas:** Tingkatan prioritas (Low, Medium, High) dengan indikator warna.
- **Statistik Ringkas:** Dashboard indikator total tugas, tugas pending, dan tugas selesai.
- **Tenggat Waktu:** Fitur penanggalan batas waktu penyelesaian tugas.

## Teknologi yang Digunakan
- **Framework:** Laravel 11
- **Database:** MySQL
- **Styling:** Tailwind CSS (via CDN)
- **Version Control:** Git & GitHub
